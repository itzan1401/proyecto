Sobre el proyecto

Este proyecto de aula tiene como objetivo integrar distintas herramientas digitales en la creación de contenidos multimediales. A través del uso de plataformas como Animaker, Adobe Express, Visual Studio Code, HTML, CSS y GitHub Pages, se busca desarrollar productos como animaciones, álbumes interactivos, folletos digitales y páginas web, lo que permite una presentación más atractiva y organizada de la información vista durante el módulo.
